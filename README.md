# Task Tracker

A small command-line task tracker, written as a practice project for the Git tutorial.

## Goal

Learn the core Git workflow by building something real:

- initialising a repository and making commits
- working on feature branches
- merging branches back into `main`
- resolving a merge conflict
- tagging a release
- reverting a change that turned out to be a bad idea

## Usage

```sh
python3 tasks.py add "Buy milk"   # add a task
python3 tasks.py list             # show all tasks
python3 tasks.py done 1           # mark task 1 as completed
```
